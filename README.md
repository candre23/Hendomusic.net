# Hendomusic.net
Code and backups for [hendomusic.net](https://www.hendomusic.net/)

Scrapers, utilities, scripts, and lists are released into the public domain.  Thumbnail backups remain the property of their creators and are preserved for archival purposes only.  Hendomusic.net is a hobby project operated solely for the love of local music.  I have no ads and no sponsors.  I do not accept donations.
